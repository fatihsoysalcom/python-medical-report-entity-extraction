# Python Medical Report Entity Extraction

This Python script demonstrates basic medical entity extraction from free-text reports. It uses standard library regular expressions to identify symptoms, diagnoses, medications, and measurements, converting unstructured text into a structured format. This forms the foundational step for automated clinical decision support systems.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
